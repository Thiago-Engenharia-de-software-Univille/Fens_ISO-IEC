# Fens_ISO-IEC

Trabalho ISO/IEC — Fundamentos de Engenharia de Software (Univille, 2026).

O que significa ISO? IEC? ABNT?

## Roteiro do trabalho

- O que significa ISO? IEC? ABNT?
- Descrição das normas ISO/IEC 14598-5, 12119, 12207, 90003, 15504 e 25000
- Modelos de qualidade: como a ISO/IEC 25000 está organizada
- Qualidade no ciclo de vida do software, da elicitação de requisitos até o fim do uso
- Conceitos de qualidade em uso, qualidade interna e qualidade externa

## Arquivos

| Arquivo | O que é |
|---|---|
| `index.html` | Apresentação de slides (tema de boot de sistema operacional; o `.iso` é só trocadilho) |
| `trabalho.html` | Trabalho escrito, formatado para impressão |

| `COMO_FUNCIONA.md` | Como a apresentação funciona e como editar |

## Apresentação

Abra `index.html` no navegador. A tela se ajusta a qualquer tamanho, de projetor a celular.

- `→` / `Espaço` / `PageDown`: avançar · `←` / `PageUp`: voltar
- `↑` `↓`: rolar a janela, se o conteúdo não couber
- `M`: menu de boot (roteiro) · `F`: tela cheia
- Funciona com passador de slides (clicker) e com gesto de deslizar no celular
